# AI-Powered Emergency Health Response & Rural Support System (EHRS)

## Overview
A web-based platform that detects health emergencies using symptoms, sends alerts to hospitals, ambulances, and nearby doctors, and works in low network areas.

## How to Run
1. Navigate to this directory in your terminal.
2. Install dependencies (recommended to use a virtual environment):
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Flask application:
   ```bash
   python app.py
   ```
4. Open `http://127.0.0.1:5000` in your web browser.
